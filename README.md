# Polygon
Simple java application allowing user to place lines and create/edit polygons.

## Functionality
 * **Creating line** - User can place down lines by dragging left
 * **Adding point** - If there is at least one line on the canvas it is possible to add points/create new lines by left-clicking
 * **Adding point to an existing line** - It is possible to add point in the center of an existing line by clicking mouse wheel
 * **Removing point** - Clicking delete removes point closest to mouse cursor
 * **Changing point position** - It is possible to change position of a point by dragging right
